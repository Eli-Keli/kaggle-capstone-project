# AI Agents for Accessibility: Kenyan/African Context
## Project Ideas Focused on Inclusivity in Tech for Persons with Disabilities

---

### 1. **Uwezo Access Hub** 🌍
**Track:** Agents for Good  
**Target Users:** Persons with visual, hearing, and mobility impairments in Kenya

**Description:**
A multi-agent system that provides personalized accessibility assistance for PWDs navigating digital services, education, and employment opportunities in Kenya.

**Core Features:**
- **Visual Assistance Agent:** Describes images, reads text, provides navigation guidance
- **Sign Language Interpreter Agent:** Converts text/audio to Kenyan Sign Language (KSL) instructions
- **Job Matching Agent:** Matches PWDs with accessible employment opportunities
- **Education Navigator:** Helps find accessible learning resources and institutions

**Technical Implementation:**
- Sequential agents for multi-step workflows
- Memory service to remember user preferences and accessibility needs
- Custom tools for Kenyan context (M-PESA integration, local resources database)
- MCP integration for document processing
- A2A protocol for inter-agent communication

**Key Concepts (5+):**
1. Multi-agent system (Sequential + Parallel)
2. Custom tools + MCP
3. Sessions & Memory
4. Context engineering
5. Observability

**Impact:**
Addresses digital divide for Kenya's 2.2M+ PWDs, supporting SDG 10 (Reduced Inequalities)

### 2. **Afya Connect: Healthcare Navigation for PWDs** 🏥
**Track:** Agents for Good  
**Target Users:** PWDs seeking healthcare services in Kenya

**Description:**
An intelligent agent system that helps PWDs in Kenya find accessible healthcare facilities, book appointments, get medication reminders, and access health information in accessible formats.

**Core Features:**
- **Facility Finder Agent:** Locates wheelchair-accessible hospitals/clinics
- **Appointment Coordinator:** Books appointments with SMS/USSD for feature phones
- **Medical Information Agent:** Provides health info in simplified Swahili/English
- **Emergency Response Agent:** Connects to emergency services with accessibility accommodations

**Technical Implementation:**
- Parallel agents for simultaneous information gathering
- Long-running operations for appointment booking
- Database session service for patient history
- Google Search tool for real-time facility information
- Custom tools for USSD/SMS integration

**Key Concepts (6):**
1. Multi-agent system (Parallel + Sequential)
2. Long-running operations
3. Sessions & Memory (DatabaseSessionService)
4. Custom tools + Google Search
5. Context compaction
6. Observability

**Impact:**
Improves healthcare access for PWDs in underserved areas

### 6. **Sauti Yangu: Digital Voice for PWDs** 🗣️

**Technical Implementation:**
- Parallel agents for multi-modal communication
- Custom tools for Swahili language processing
- Sessions for conversation context
- MCP for document/image processing
- Code execution for text processing

**Key Concepts (5):**
1. Multi-agent system (Parallel)
2. Custom tools
3. MCP tools
4. Sessions & Memory
5. Observability

**Impact:**
Enables communication for 500K+ Kenyans with communication disabilities

## Selection Criteria for Final Proposal:

1. **Feasibility:** Can be built within timeline with available tools
2. **Impact:** Addresses significant accessibility gap in Kenya
3. **Technical Depth:** Demonstrates 5+ key course concepts
4. **Innovation:** Novel approach to accessibility challenges
5. **Scalability:** Can expand to other African countries
6. **Data Availability:** Can access/create necessary data for Kenyan context
