# 5-Day AI Agents Intensive Course - Capstone Project

> **Accessible Services Navigator for Nairobi** — A multi-agent system helping persons with disabilities find accessible healthcare and social services.

## 📚 About This Repository

This repository contains my capstone project for the **Kaggle 5-Day AI Agents Intensive Course** powered by Google's Agent Development Kit (ADK).

## 🎯 Project Overview

The **Accessible Services Navigator** is a practical implementation of multi-agent architecture that addresses a real-world challenge: helping persons with disabilities in Nairobi discover and access healthcare facilities and social services that meet their specific accessibility needs.

### Key Features

- **Multi-agent orchestration** using Google ADK
- **Custom tools** for dataset search and web enrichment
- **Structured data schemas** with Pydantic validation
- **Curated Nairobi dataset** with accessibility annotations
- **Educational Jupyter notebooks** for Kaggle

## 🛠️ Tech Stack

- **Framework**: Google Agent Development Kit (ADK)
- **Language**: Python 3.10+
- **Models**: Gemini 2.5 Flash Lite
- **Data Validation**: Pydantic v2.0+
- **Data Processing**: Pandas + PyArrow

## 📖 Course Materials

- **Day 5**: Agent-to-agent communication and deployment
